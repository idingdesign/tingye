Tingye Privacy Policy

**生效日期 / Effective date:** 2026-10-12 **产品 / Product:** 听页（Tingye）Chrome 扩展 **运营方 / Operator:** IDING DESIGN（[iding.net](https://iding.net)） **联系 / Contact:** 通过 [iding.net](https://iding.net) 网站公示渠道联系

本文说明扩展如何处理数据。使用本扩展即表示你理解下列做法。 This policy describes how the extension handles data. By using Tingye you acknowledge the practices below.

---

1. 我们收集什么？ / What we collect

**听页扩展本身不收集、不上传、不出售个人身份信息。** 我们不运营用于分析用户行为的后台、不记录你的浏览历史，也不要求账号登录。

**Tingye does not collect, upload, or sell personally identifiable information.** There is no analytics backend for browsing history, and no account sign-in is required.

本地仅保存你主动配置的设置（阅读区域、方式、目标语言、语音引擎、语速等），使用 Chrome 的 `chrome.storage.local`，数据留在你的设备上。

Settings you choose are stored locally via `chrome.storage.local` on your device only.

---

2. 可选 OpenAI API Key

若你启用 **OpenAI TTS**，可在扩展选项中粘贴自己的 API Key。该 Key：

- 仅保存在本机 `chrome.storage.local` - 仅用于向 `https://api.openai.com/` 发起你触发的语音合成请求 - **不会**发送到 iding.net 或其它非 OpenAI 服务器

If you enable OpenAI TTS, your API key is stored only on-device and used solely for OpenAI TTS requests you initiate. It is never sent to iding.net.

---

3. 朗读与翻译时发送的内容 / Data sent when you use translate or TTS

当你点击开始朗读（或自动阅读触发）时，扩展会从**当前标签页**提取可见文本（按你选择的「仅正文 / 仅元素 / 全部」），并可能将**文本片段**发送至下列第三方，以便完成翻译或语音合成：

| 服务 | 用途 | 典型端点 | | --- | --- | --- | | Microsoft Translator / Edge | 翻译 | `api-edge.cognitive.microsofttranslator.com`、`edge.microsoft.com` | | Google Translate（gtx） | 翻译兜底 | `translate.googleapis.com` | | MyMemory | 翻译兜底 | `api.mymemory.translated.net` | | Microsoft / Bing Speech | 神经 TTS | `speech.platform.bing.com`（含 WebSocket） | | OpenAI（可选） | TTS | `api.openai.com` |

这些请求由你的浏览器直接发出。第三方如何处理数据以其各自隐私政策为准。请勿对高度敏感或受法规限制的内容使用云端翻译/TTS。

Page text chunks are sent only when you use those features. Third-party processing is governed by their own policies. Do not send highly sensitive content through cloud translate/TTS.

浏览器内置 `speechSynthesis` 路径通常在本地或系统语音服务完成，不经过上述云端 TTS（仍可能使用云端翻译，取决于你是否开启翻译）。

---

4. 主机与脚本权限说明 / Host & scripting permissions

| 权限 | 原因 | | --- | --- | | `http://*/*`、`https://*/*` | 在普通网页注入内容脚本，提取文本并同步高亮当前朗读段落 | | 翻译 / TTS 相关主机权限 | 仅用于上表所列服务，不用于广告或追踪 | | `storage` | 保存设置与可选 API Key | | `tabs` / `activeTab` / `scripting` / `webNavigation` | 读写当前页、自动阅读时感知导航 | | `sidePanel` | 显示侧栏 UI | | `declarativeNetRequest` | 调用 Microsoft 语音时修正 Origin / User-Agent（与常见 edge-tts 做法一致） |

扩展无法在 `chrome://`、Chrome 网上应用店页面、部分 PDF 查看器等受限页面注入脚本。

---

5. 我们不做什么 / What we do not do

- 不出售用户数据 - 不将页面全文批量上传到 iding.net - 不在未使用朗读/翻译功能时向翻译或 TTS 服务商发送页面内容 - 不将 OpenAI Key 同步到云端（本扩展不提供云同步）

---

6. 儿童 / Children

本产品面向一般网页辅助阅读，不专门面向儿童收集数据。
